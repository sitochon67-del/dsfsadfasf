# Iconos opcionales (alta resolución)

Por defecto se usa el GIF oficial **`../procesando.gif`** a **175×175 px** (igual que registro.pse.com.co).

Si colocas PNG/WebP aquí (`frame-01.png`, `frame-02.png`, …), se activa el modo **volteo** en lugar del GIF.

Recomendado para iconos sueltos: **350×350** o **512×512** px, fondo transparente.
